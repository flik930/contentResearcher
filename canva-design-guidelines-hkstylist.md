# HKStylist Instagram Post Design Guide

## Colors
- **Mint Green** 薄荷綠 `#00D4AA` (主色)
- **Coral Pink** 珊瑚粉 `#FF6B6B` (輔色)
- **Gold** 金色 `#FFD700` (強調色)
- **White/Gray** (背景色)

## Fonts
- **English**: Montserrat/Poppins (Bold for headlines, Regular for body)
- **Chinese**: Noto Sans TC (繁體中文)

## Instagram Post Template (1080x1080px)

### Layout Structure
1. **Header** (Top 15%): Logo + Title
2. **Main Visual** (Middle 60%): Hair photo/before-after
3. **Footer** (Bottom 25%): Text + CTA button

### Design Rules
- Logo: Bottom-right corner, small
- Text: Max 2-3 lines, high contrast
- CTA Button: Mint green background
- White space: Generous margins

### Content Types
1. **Before/After**: Split-screen layout
2. **Stylist Spotlight**: Portrait + work samples  
3. **Hair Tips**: Simple infographic style
4. **Testimonials**: Quote + customer photo + stars

### Canva Setup
1. Create brand kit with HKStylist colors
2. Save font combinations
3. Use circular frames for portraits
4. Add consistent logo placement

### Text Guidelines
- Headlines: 32-40px, Bold
- Body text: 16-20px, Regular
- Mix Chinese/English naturally
- Keep messages short and clear

## Lovely Backgrounds for Girls

### Gradient Backgrounds
1. **Mint to White**: Soft vertical gradient (#00D4AA to #FFFFFF)
2. **Coral Sunset**: Warm gradient (#FF6B6B to #FFE4E4)
3. **Gold Shimmer**: Subtle gold gradient (#FFD700 to #FFF9E6)
4. **Pastel Dreams**: Multi-color soft gradient (mint → coral → white)

### Pattern Backgrounds
1. **Subtle Dots**: Small white dots on mint green
2. **Soft Waves**: Gentle curved lines in coral pink
3. **Geometric Shapes**: Light triangles or circles
4. **Marble Texture**: White marble with gold veins

### Photo Backgrounds
1. **Blurred Beauty Tools**: Soft focus scissors, brushes
2. **Flower Petals**: Cherry blossom or rose petals
3. **Bokeh Lights**: Dreamy light circles
4. **Silk Fabric**: Smooth, flowing textures
